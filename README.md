# Автотесты для сервиса Stellar Burgers (Спринт 5)

UI-автотесты на Python с использованием `pytest` и `Selenium WebDriver`.

## Реализованные проверки
- **Регистрация (`test_registration.py`):** успешная регистрация нового пользователя и проверка ошибки при вводе некорректного пароля (менее 6 символов).
- **Вход в аккаунт (`test_login.py`):** авторизация через кнопку «Войти в аккаунт» на главной, кнопку «Личный кабинет», форму регистрации и форму восстановления пароля.
- **Личный кабинет и навигация (`test_profile.py`):** переход в личный кабинет, переход из личного кабинета в конструктор (по кнопке «Конструктор» и логотипу) и выход из аккаунта.
- **Раздел «Конструктор» (`test_constructor.py`):** проверка переключения вкладок «Булки», «Соусы» и «Начинки».

## Запуск тестов
```bash
pytest -v
```
